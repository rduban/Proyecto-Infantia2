# Proyecto-Infantia2
Un estudio sobre cuidado infantil liderado por Universidad del Norte en el 2023.
En este repositorio se alojan los scripts desarrollados para la construcción, limpieza y tratamiento de los datos del proyecto. Asimismo, se incluyen scripts desarrollados para el anáisis psicométrico, analisis exploratorio de los datos además del modelamiento de los mismos.
